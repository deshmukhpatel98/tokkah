TAPE — turn-taking gate

The falsification test for DESIGN.md §1.1c. Boland et al. (2021) measured turn transitions at 297 ms face to face and 976 ms over Zoom. Latency alone explains about 797 of that, so ~179 ms is Zoom destroying the cues people use to predict a turn ending. This page checks whether raw audio wins that back — and whether the pre-turn inhale really arrives before the words. Needs two machines and headphones on both.

Run sheet — read this first

Two people, two computers, headphones on both, in different rooms (if you can hear each other through the air, the timing is meaningless).

  1. Both of you: type the same room word and a run label like run1.
  2. Run A (raw): both leave raw audio ticked, press Join. Check the line next to Join says your modes match.
  3. Whoever sees you ask: read the question out loud, then stop talking. Whoever sees you answer: say "yes" or "no" the instant you know — do not wait to be polite. The page advances by itself after each answer.
  4. After ~10 questions press swap asker so the other person answers for a while. Aim for 20+ scored turns (bottom table), then export CSV.
  5. Run B (processed): reload the page, both untick raw audio, use a new label like run2, and repeat. That A/B is the whole experiment.
  6. If something goes weird mid-question, the asker presses discard this one.

The verdict panel judges the raw run against the gate. A FAIL is information, not a bug — it would mean the design's central inference is wrong, which is exactly what this page exists to find out before anyone builds the rest of it.
