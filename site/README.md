# Tokkah — one-page investor site

Static. No build. Open `index.html` over http (modules will not load from `file://`).

```bash
cd site
python3 -m http.server 8765
# then http://127.0.0.1:8765
```

A server is already running there if this machine started one.

Intended home: `tokkah.com`. The product stays at `room.tokkah.com`.

Every number on the page is taken from `MEASURED.md`, `README.md`, `COST-MODEL.md`, `FATIGUE.md`, and `LATENCY-150.md` in this repo. Comparative claims against Zoom and Google Meet are omitted on purpose.
