Tokkah for macOS

A video call that should feel like the other person is in the room. This is the native half — built because a browser will not give you the clocks or the audio thread the goal requires.

Install

curl -fsSL https://room.tokkah.com/macos/install.sh | sh

Installs to ~/.local/bin/tk. No security dialog to click through: files fetched by curl are not quarantined, so this path never meets Gatekeeper. The download is checked against a SHA-256 in a signed manifest, and from then on tk updates itself and verifies an Ed25519 signature on every update before applying it. Read the script first if you like — it is right here, 50 lines.

Use it

tk --listen 7001 --peer <other-mac-ip>:7001 --window

Run it on both Macs. --window opens the picture; without it you get audio and a latency read-out. Add --video camera to send your camera, or --video <clip.mov> to send a file. It asks for microphone and camera permission the first time, prints its latency budget on start, and then one line a second.

Measured between two processes on one Mac, so the network contributes nothing and both ends share one clock — these are the pipeline itself, not an estimate. Audio and video ride one UDP socket, so there is one port and one hole to punch. Keyframes are sent on request rather than on a timer, so a healthy call never pays for one and a late joiner recovers in about 300 ms.

Honest limits

Apple silicon only. It is a command-line tool that can open a window, not yet an app with buttons. Audio and video are encrypted with AES-256-GCM, keys agreed per call over X25519 and salted with the room code — so a listener on any hop gets nothing, and neither does anyone who was not told the code. What it does not stop is someone who knows the code and can sit in the middle of the path: that needs an identity that outlives a call, which does not exist here yet. There is no forward error correction: a lost packet is a concealed millisecond of audio, and a lost video frame is repaired by asking for a new keyframe, which costs about one frame. Two machines behind ordinary routers find each other with --room and talk directly, with no relay in the middle; a symmetric NAT on either side will defeat that, and there is no fallback yet when it does. It is signed by us, not notarised by Apple, which is exactly why the install goes through curl. And it is an early build being changed several times a day — it updates itself, so it will not stay this one for long.
