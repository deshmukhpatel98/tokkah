Someone wants to talk to you

Tokkah is a small, direct video call for macOS. Audio is sent losslessly and nothing goes through a server — the two machines talk to each other.

Room name
—
  1. Install it — one line in Terminal, about ten seconds. curl -fsSL https://room.tokkah.com/macos/install.sh | sh
  2. Open Tokkah from your Applications folder. Allow the camera and microphone when macOS asks — it needs both to be a call.
  3. Type the room name above and press Join. You will see yourself straight away; the other person appears when they join the same room.

Both people have to be in the call at the same time — there is no ringing and nothing is stored. The room name is also the encryption key, so pick a fresh one for anything you would not say in public, and it never leaves your two machines. What this is and how fast it is.
